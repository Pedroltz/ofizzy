# Contribuir com o Ofizzy

O [guia de contribuição](docs/CONTRIBUTING.md) é a referência para ambiente, fluxo de branches, commits e validações. Leia também as [instruções do projeto](AGENTS.md).

- Relate bugs com o formulário de issue, passos para reproduzir e dados fictícios.
- Proponha mudanças de comportamento antes de alterações grandes.
- Direcione contribuições a `develop`; `main` recebe releases.
- Preencha o template de PR com alterações e resultados reais de validação.

Vulnerabilidades devem seguir a [política de segurança](SECURITY.md). A disponibilidade pública do código não altera os [direitos reservados](LICENSE).
