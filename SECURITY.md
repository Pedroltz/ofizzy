# Segurança

A [política técnica de segurança](docs/SECURITY.md) descreve proteção de sessões, isolamento de organizações, dados e certificados fiscais.

Para reportar uma vulnerabilidade, use **Report a vulnerability** na [área de segurança do repositório](https://github.com/Pedroltz/ofizzy/security/advisories/new), quando disponível. Se o recurso estiver indisponível, consulte os canais de contato publicados no [perfil do mantenedor](https://github.com/Pedroltz) para combinar um canal privado antes de compartilhar detalhes.

Não publique vulnerabilidades, credenciais, documentos, XMLs fiscais, certificados ou dados de clientes em issues ou pull requests. Descreva a versão/commit afetado, impacto e reprodução mínima com dados fictícios no relato privado.

O projeto está em desenvolvimento ativo; correções são destinadas à linha atual em `develop`, com releases em `main`. Não existe compromisso de manutenção de versões antigas nem prazo de resposta garantido.
